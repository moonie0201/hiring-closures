Which companies are closing job postings fastest?

Ranked from the free file: every board measured in the five-provider free file, stock measured on 2026-10-15, changes through 2026-10-17. Rebuilt daily as the 72-hour window rolls forward.

How every number here is computed. For each company, the first day it appears in the file sets open at start. Over the days after it, added is the sum of added and closed the sum of removed; the first day's own added/removed describe the change from a day outside the file and are not used, which is also what keeps a first-day baseline (added empty) out of every sum. Closure share = closed ÷ (open at start + added): the fraction of every posting that was on the board at any point in the window and was gone by the end. Net = added − closed, and open now = open at start + added − closed holds for every row in this build except ashby:G2, ashby:aaru, ashby:d-matrix, ashby:hawkeyeinnovations, ashby:hims-and-hers, ashby:meridianlink, ashby:signoz, ashby:wearebeyondsports, greenhouse:amwell, greenhouse:backblaze, greenhouse:baringa, greenhouse:beamtherapeutics, greenhouse:bestversionmedia, greenhouse:blueskyinnovators, greenhouse:classpass, greenhouse:coupang, greenhouse:dscout, greenhouse:galaxydigitalservices, greenhouse:garnerhealth, greenhouse:generalatlantic, greenhouse:immersive, greenhouse:junoveterinary, greenhouse:morsecorp, greenhouse:n26, greenhouse:officeally, greenhouse:oldcastlebuildingenvelope, greenhouse:oneoncology, greenhouse:paretocaptiveservicesllc, greenhouse:recordedfuture, greenhouse:sbusa, greenhouse:sensei, greenhouse:shennonbiotechnologies, greenhouse:smavagmbh, greenhouse:starburst, greenhouse:systemstechnologyresearch, greenhouse:thinkzone, greenhouse:tosscareers, greenhouse:trgscreen, greenhouse:tsg, greenhouse:via, greenhouse:workatbackbase, lever:Zanskar, lever:dnb, lever:egen, lever:fehrandpeers, lever:nfq, recruitee:barentskrans, recruitee:diakonieauerbachev, rippling:branch, rippling:the-channel-company-careers (a day inside the window is missing from the file). What a removed record means. A job posting that was returned by a company's public careers API on one day was no longer returned on a later day. It is not a statement that anyone was hired, that a role was cancelled, or that anyone lost a job. Postings also stop being returned for reasons we cannot observe, including reposting under a new ID, board migrations, and provider outages.

A board's first observed day is a baseline, not hiring. The first time we see a board, every posting on it is new to the dataset. That day is published with added empty, and nothing on this site sums it as growth. The first day with complete snapshots on both sides of the diff is 2026-08-28.

No job advertisement text, ever. The body of a job ad is the employer's own copyrighted work; it is never stored, reproduced, excerpted or summarised, in any tier. The free file carries no free text at all — no titles, no locations, no URLs.

Measurement. Page views are counted with Google Analytics in a cookieless configuration: no analytics cookie is set, no client identifier is stored, IP addresses are anonymised, and advertising features are off. The only purpose is to see which pages are read and where readers arrive from.
