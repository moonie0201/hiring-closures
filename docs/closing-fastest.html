Which companies are closing job postings fastest?

Ranked from the free file: every board measured in the five-provider free file, stock measured on 2026-11-05, changes through 2026-11-07. Rebuilt daily as the 72-hour window rolls forward.

How every number here is computed. For each company, the first day it appears in the file sets open at start. Over the days after it, added is the sum of added and closed the sum of removed; the first day's own added/removed describe the change from a day outside the file and are not used, which is also what keeps a first-day baseline (added empty) out of every sum. Closure share = closed ÷ (open at start + added): the fraction of every posting that was on the board at any point in the window and was gone by the end. Net = added − closed, and open now = open at start + added − closed holds for every row in this build except ashby:baseten, ashby:blueberrypediatrics, ashby:cosuno, ashby:dyna-robotics, ashby:euphoric, ashby:humanoid, ashby:legora, ashby:maintainx, ashby:metalenz, ashby:neko-health, ashby:numeral, ashby:openai, ashby:radiant-industries, ashby:renuity, ashby:the-pinnacle-school, ashby:valkai, greenhouse:agilysys, greenhouse:authenticinsurance, greenhouse:axsometherapeutics, greenhouse:bidmachine, greenhouse:bluestone, greenhouse:brex, greenhouse:buildkite, greenhouse:cannondesign, greenhouse:codeorg, greenhouse:cooksys, greenhouse:css, greenhouse:druva, greenhouse:eositsolutions, greenhouse:fanaticsinc, greenhouse:feverup, greenhouse:fictiv, greenhouse:forgebiologics, greenhouse:georgepjohnsonexperiencemarketing, greenhouse:known, greenhouse:lightningai, greenhouse:maxcessinternational, greenhouse:navapbc, greenhouse:pandadoc, greenhouse:personalizedbeautydiscoveryincdbaipsy, greenhouse:queracomputinginc, greenhouse:shiphawk, greenhouse:sonymusicentertainment, greenhouse:thechempetitivegroupllc, greenhouse:zencoder, lever:dialogdesign, lever:ellevationeducation, lever:enveda, lever:h1, lever:idt, lever:nexuse-group, lever:noodle, lever:uvcyber, lever:windownation, recruitee:comhard, rippling:bayaud-works, rippling:fluidai-medical-careers, rippling:quavo-inc, rippling:shelter-inc, rippling:sunnymac-careers, rippling:visio-lending-careers (a day inside the window is missing from the file). What a removed record means. A job posting that was returned by a company's public careers API on one day was no longer returned on a later day. It is not a statement that anyone was hired, that a role was cancelled, or that anyone lost a job. Postings also stop being returned for reasons we cannot observe, including reposting under a new ID, board migrations, and provider outages.

A board's first observed day is a baseline, not hiring. The first time we see a board, every posting on it is new to the dataset. That day is published with added empty, and nothing on this site sums it as growth. The first day with complete snapshots on both sides of the diff is 2026-08-28.

No job advertisement text, ever. The body of a job ad is the employer's own copyrighted work; it is never stored, reproduced, excerpted or summarised, in any tier. The free file carries no free text at all — no titles, no locations, no URLs.

Measurement. Page views are counted with Google Analytics in a cookieless configuration: no analytics cookie is set, no client identifier is stored, IP addresses are anonymised, and advertising features are off. The only purpose is to see which pages are read and where readers arrive from.
